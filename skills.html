HTML glossary

Element
A complete HTML unit composed of an opening tag, content, and a closing tag.
Tag
The angle-bracket markers used to define the start and end of an element, such as <p> for an opening tag and </p> for a closing tag.
Attribute
Extra information included in an opening tag that provides additional details about the element, such as href, src, or alt.
Void Element
A type of element that cannot have children and does not require a closing tag, such as <img>, <br>, or <input>.
Semantic Html
The practice of using HTML elements that describe the actual meaning of the content (e.g., <header>, <main>, <nav>) instead of just its visual appearance.
